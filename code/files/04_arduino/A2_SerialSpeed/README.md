# A2：Unityの接触・速度に連動する振動

115200 baudで整数と改行を受信します。例: `0\n`、`1\n`、`8\n`。0〜13をLED点灯数と目標振幅へ対応させます。Unity側の速度区間から整数へ変換する部分はこのスケッチに含みません。

値が1へ変化すると65 Hz・振幅30000の接触振動を100 ms出し、その後250 Hzの通常振動へ戻ります。同じ1を受信しても再トリガーしません。0または2〜13への変化で接触振動をすぐ解除します。通常振幅は `level*32767/13` の整数除算で、バッファごとに差の5%だけ追従します。0への変化も通常フェードのため瞬時に完全ゼロにはなりません。

`SerialLevelParser`、`VelocityController`、`I2sOutput` に責務を分けています。不正文字や過長行の扱いとI2Sエラー処理は原本から修正しました。正常な0〜13のコマンドに対する周波数・条件・フェードは維持しています。

原本のALL_RIGHT形式を保持しているため、I2S出力先が解釈するチャンネルとサンプル周期は実機確認が必要です。合成波形図は44100 samples/sを前提としたPCMで、振動子の出力計測ではありません。
