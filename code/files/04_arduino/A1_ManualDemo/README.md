# A1：単・ダブルクリックの振動提示

M5Atom Matrixのボタンを1回押し、300 ms経過するとON/OFFが切り替わります。300 ms以内の2回押しでモード1=160 Hz、モード2=500 Hzを切り替えます。緑は停止、赤は振動中、5×5 LEDの数字がモードを示します。

`ManualController` がボタン・時間・動作モードを管理し、`SineOscillator` が位相を保って左右同一の16 bit PCMを生成します。OFF中はゼロを出力し、位相を進めない原本仕様です。2回目が期限後に到着した場合の判定だけを修正しています。

依存、ピン、コンパイル手順は親READMEを参照してください。実機配線・出力振幅・操作感は今回未確認です。I2Sエラーはマゼンタ表示で停止します。
